
# PawMerge 🐾

A creative Android pet-merging game where players combine dogs to unlock new multi-tailed breeds and progress through increasingly rare evolutions.

Built using Kotlin and Android Studio, PawMerge focuses on fun progression systems, engaging visuals, and interactive gameplay mechanics inspired by merge-style mobile games.

---

## Features

- 🐶 Merge dogs to create evolved breeds
- ✨ Unlock unique multi-tailed dog variations
- 🎮 Progression-based gameplay loop
- 📱 Mobile-first Android experience
- 🎨 Custom UI and visual styling
- 🧠 Game logic and state management
- 🐕 Multiple dog types and rarity progression

---

## Tech Stack

- Kotlin
- Android Studio
- Jetpack Compose
- Game Logic Systems
- UI/UX Design
